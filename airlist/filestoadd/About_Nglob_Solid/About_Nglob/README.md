# About Nglob — Solid.js + TypeScript

1. Перенесите `src/about` в проект и `public/nglob-about` в его `public`.
2. На маршруте `/about`: `import { AboutNglobPage } from './about';` → `<AboutNglobPage />`.
3. Параметры: `links` переопределяет адреса, `assetBase` — путь к ресурсам (`/nglob-about/assets`).
4. Компонент содержит один `<main id="main">`; утверждённые шапку, футер и Chat сохраните снаружи в одном экземпляре. Не меняйте их логотипы, кнопки, соцсети, платежи, карточки и юридическую строку.
5. В существующем футере обновите только четыре группы ссылок по `footerGroups` в `src/demo/SiteChrome.tsx`: Services — 5, Company — 2, Partners — 2, Support — 2. Новый How it works — `/how-it-works`. `src/demo` нужен для просмотра; повторную общую оболочку в сайт не добавляйте. Светлая палитра футера ограничена страницей About.
6. Для просмотра: Node.js ≥22.13; `npm ci`, `npm run build`, `npm run preview`. Откройте `/about`.
7. Проверка типов: `npm run typecheck`. Сборка заранее формирует HTML, затем подключает Solid hydration.
8. Title, description, canonical, Open Graph и JSON-LD для `/about` заданы в `index.html`; перенесите их в метаданные роутера без дублирования существующей Organization.
9. `noindex,nofollow` относится только к приложенному просмотру; публичная страница использует настройки основного сайта.
10. Сохраните локальные ресурсы, шрифт и CSS; зависимостей от React, внешних шрифтов и API нет.
11. Раскрытия и визуальные примеры работают на странице. Трекинг, Photo Scan и кабинет здесь объясняют сервис.
12. После подключения проверьте мобильное меню общей оболочки, раскрытия, клавиатуру и прямые ссылки страницы.
