# Nglob Referral Partners — комплект для программиста

Компонент согласованной страницы для существующего сайта на Solid.js и Vite. В комплект входят TSX, локальные стили, изображения, шрифт, типы и пример подключения. Это интеграционный комплект; отдельная демонстрация всех состояний и подробные материалы QA доступны в полном архиве. Они не нужны для загрузки рабочего компонента.

## Состав

| Путь | Назначение |
| --- | --- |
| `integration/referral-partners/` | Компонент со всеми локальными зависимостями; копировать целиком |
| `examples/IntegrationExample.tsx` | Типизированный адаптер действий к существующему приложению |
| `README_RU.md` | Инструкция именно к этому компактному комплекту |

Корневого `package.json` и отдельного приложения здесь нет: компонент использует сборку и установленный Solid.js основного сайта. Ненужные для интеграции демонстрационные формы, глобальная оболочка сайта, скриншоты и тестовые зависимости исключены. Функциональность публичного компонента и его визуальные ресурсы сохранены.

## Установка и подключение

1. Скопируйте **всю** папку `integration/referral-partners/` в исходники основного проекта, например в `src/features/referral-partners/`.
2. Используйте имеющийся `solid-js`; проверенная версия — **1.9.15**. Не устанавливайте вторую копию Solid.js внутри скопированной папки. Проект должен обрабатывать Solid TSX, CSS и импорты WebP, PNG и WOFF2. В проверенной конфигурации TypeScript используются `jsx: "preserve"`, `jsxImportSource: "solid-js"`, `moduleResolution: "Bundler"` и `vite/client`.
3. Подключите компонент в маршрут Referral Partners и передайте реальный обработчик действий приложения. Пути импорта меняются только в зависимости от выбранного места копирования.

```tsx
import {
  ReferralPartners,
  type ReferralAction,
} from "./features/referral-partners";

type PartnersRouteProps = {
  onPartnerAction: (action: ReferralAction) => void;
};

export default function PartnersRoute(props: PartnersRouteProps) {
  return <ReferralPartners onAction={props.onPartnerAction} />;
}
```

`examples/IntegrationExample.tsx` показывает полный адаптер регистрации, входа, личной ссылки, представления компании и правил программы. Его импорт `../integration/referral-partners` соответствует расположению внутри архива; при переносе примера в основной проект укажите фактический путь к скопированной папке. Реальные функции приложения передаются через обязательный параметр `app`, а адреса услуг — через `serviceLinks`; вымышленных API и маршрутов в адаптере нет.

Компонент уже содержит `<main>` и один H1. Размещайте его между существующими header и footer, не внутри другого `<main>`. По умолчанию глобальная оболочка не добавляется. Необязательные `header` и `footer` принимают JSX существующей оболочки. В одном документе используйте **один экземпляр** страницы: идентификаторы её секций и полей фиксированы.

Стили компонента импортируются автоматически и ограничены `#rp`. Локальный шрифт зарегистрирован как `NglobReferralInter`. Не переносите стили полной демонстрации поверх основного сайта.

### Ссылки на услуги

Необязательный `serviceLinks` позволяет передать фактические адреса услуг основного сайта через ключи `homeMoving`, `fewItems`, `storage`. Экспортируемый тип `ReferralServiceLinks` требует все три адреса, если объект передан. Допустимы фактические относительные маршруты или полные URL; путь размещения приложения учитывает его роутер. Пропуск всего параметра сохраняет адреса из согласованного макета:

```tsx
import {
  ReferralPartners,
  type ReferralAction,
  type ReferralServiceLinks,
} from "./features/referral-partners";

export function PartnersRouteWithServices(props: {
  onPartnerAction: (action: ReferralAction) => void;
  serviceLinks: ReferralServiceLinks;
}) {
  return (
    <ReferralPartners
      onAction={props.onPartnerAction}
      serviceLinks={props.serviceLinks}
    />
  );
}
```

| Ключ | Адрес по умолчанию |
| --- | --- |
| `homeMoving` | `https://www.nglob.com/services/home-moving` |
| `fewItems` | `https://www.nglob.com/services/few-items` |
| `storage` | `https://www.nglob.com/services/storage` |

Это унаследованные адреса, а не подтверждение доступности этих страниц. Перед публикацией сопоставьте их с реальной маршрутизацией. Настройка адресов сохраняет подписи и визуал ссылок.

### Запуск и сборка

Запускайте команды **из корня основного проекта**, после подключения компонента. Если в его `package.json` используются стандартные имена скриптов:

```sh
npm run dev
npm run build
```

При других именах используйте эквивалентные команды проекта. Выполните также его проверку TypeScript; если установлен TypeScript и настроен подходящий `tsconfig.json`, это `npx tsc --noEmit`. Сам компактный архив не объявляет npm-скрипты. Для запуска отдельного макета используйте полный архив с закреплёнными зависимостями и его собственной инструкцией.

В проверенной сборке Vite задано `build.assetsInlineLimit: 0`, поэтому маленькие изображения остаются отдельными кешируемыми файлами. При необходимости добавьте **это поле** в существующую конфигурацию `build`, сохранив остальные настройки проекта. Полностью заменять конфигурацию сайта не нужно.

## Публичный API

Основной экспорт — `ReferralPartners`; экспортируются `ReferralPartnersProps`, `ReferralServiceLinks`, `ReferralAction`, `ReferralView`, `ReferralIntent` и `ReferralController`. `onAction` обязателен и проверяется также во время выполнения. Необязательный `mode="integrated"` оставлен для совместимости; публичный компонент не поддерживает демонстрационный режим.

| Prop | Назначение |
| --- | --- |
| `onAction` | Обязательная функция `(action: ReferralAction) => void` |
| `serviceLinks` | Необязательный объект из трёх адресов услуг |
| `header`, `footer` | Необязательные элементы `JSX.Element` существующего сайта |
| `onReady` | Необязательная функция `(controller: ReferralController \| undefined) => void` |
| `mode` | Необязательное единственное значение `"integrated"` |

```ts
type ReferralView =
  | "join"
  | "signin"
  | "share"
  | "introduce"
  | "business"
  | "terms";

type ReferralIntent = "join" | "share" | "introduce";

interface ReferralAction {
  view: ReferralView;
  intent: ReferralIntent;
}

interface ReferralController {
  open(view: ReferralView, intent?: ReferralIntent): void;
  destroy(): void;
}

interface ReferralServiceLinks {
  homeMoving: string;
  fewItems: string;
  storage: string;
}
```

| `view` | Действие основного приложения |
| --- | --- |
| `join` | Открыть регистрацию партнёра |
| `signin` | Открыть вход в кабинет |
| `share` | Проверить вход и открыть личную ссылку / инструменты отправки |
| `introduce`, `business` | Проверить вход и открыть представление компании |
| `terms` | Открыть утверждённые правила программы |

Сохраняйте переданное `intent` при регистрации и входе, чтобы продолжить выбранный пользователем сценарий. Например, запрос личной ссылки отправляет `join` с `intent: "share"`. Контракт сообщает намерение пользователя, а не подтверждает создание аккаунта или начисление комиссии.

Необязательный `onReady(controller)` вызывается после mount; при cleanup он получает `undefined`. Контроллер `open` вызывает тот же `onAction`. Очистка при unmount удаляет обработчики; отложенные действия проверяют существование экземпляра. `destroy()` позволяет вручную завершить взаимодействия. Глобальный `window.RP` не создаётся.

Калькулятор, native FAQ, клавиатурное переключение примеров сообщений, редактирование и копирование работают локально. Для автоматического копирования нужен разрешённый Clipboard API в безопасном контексте браузера; предусмотрены выделение текста и инструкция ручного копирования. Текст примера содержит обозначенное место для ссылки, а действующую персональную ссылку выдаёт кабинет.

Сохранены согласованные уровни personal-link referrals: Partner — 6%, Pro — 8%, Ambassador — 12%. Business rates согласуются отдельно; период ограничен, пожизненная комиссия не обещается. Компания оформляет заказы в своём Business account; Nglob выполняет работу, затем выставляет счёт. Комиссия подтверждается после оплаты подходящей выполненной работы. Предложение «90 дней», расчётная база, пороги и порядок выплат не становятся утверждёнными от передачи этого кода.

## Поисковые системы и серверный HTML

Заголовки, основной текст и ответы FAQ представлены обычным JSX; они могут входить в серверный HTML. Компонент не устанавливает `noindex`, canonical или глобальные metadata. Browser API вызываются после mount. SSR самого компонента не заменяет проверку серверного маршрута и гидратации основного приложения.

В `<head>` реального маршрута через принятую в проекте систему metadata можно использовать точные title и description из согласованного макета:

```html
<title>Moving &amp; Delivery Referral Partners | Nglob</title>
<meta name="description" content="Recommend Nglob for moves and deliveries. Share a referral link or introduce a business, with clear commission levels and one partner account." />
```

Canonical должен содержать **фактический публичный URL** раздела; он намеренно не выдуман в комплекте. Для английской страницы используйте язык документа `en-GB`. Настройте SSR или prerender в основном проекте, проверьте HTML опубликованного маршрута, доступность ресурсов, его robots-настройки и включение в существующий sitemap. Метаданные добавляются один раз, без дублирования уже настроенного head.

У отдельной демонстрации в полном архиве установлен `noindex,nofollow`: не копируйте её `index.html` как production-шаблон. Доступность страницы для индексирования определяется настройками основного сайта. Специальные файлы для ИИ, обещания рекомендаций или поисковых позиций в комплект не добавлены.

## Изображения, шрифт и проверка

Все ресурсы локальные. `srcset` и `sizes` выбирают подходящее разрешение; исходные изображения сохранены как максимальные варианты. Главный снимок загружается с высоким приоритетом, остальные — отложенно; в разметке указаны размеры. Оригинальные логотипы, фотографии и иллюстрации не заменены. Объём архива и объём загрузки конкретной страницы — разные величины.

Лицензия шрифта находится в `integration/referral-partners/assets/FONT-LICENSE.txt`; сведения об иллюстративных фотографиях — в соседнем `PHOTO_NOTES_RU.txt`. Сохраняйте эти файлы. Фотографии не являются отзывами реальных клиентов.
