# Готовый компонент для Solid.js

Скопируйте всю папку `referral-partners/` в исходники существующего Solid.js-проекта с Vite. Импортируйте `ReferralPartners` из её `index.ts` и передайте обязательный `onAction`, связанный с вашим роутером. Оригинальный header/footer остаётся в оболочке основного сайта. Компонент сам содержит `<main>`; не помещайте его внутрь другого `<main>`.

Эта папка содержит только зависимости рабочего компонента и лицензии. Демонстрационные формы, глобальные стили макета и QA сюда не входят. Нужен установленный `solid-js`; использована версия 1.9.15. Полный контракт, пример подключения и границы серверной интеграции описаны в `README_RU.md` корня архива.
