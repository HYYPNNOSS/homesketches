# Nglob Contact Us — Solid.js / TSX · 1.0.1

Утверждённая страница Contact Us с иллюстрацией **Dialogue** перенесена в **Solid.js + TypeScript**. **Этот пакет заменяет предыдущую React-версию для проекта Solid.js.** Это компоненты интерфейса с состоянием, формами и адаптивной вёрсткой. Выбранная иллюстрация, тексты, цвета и геометрия логотипов сохранены.

**Программисту нужно передать весь этот комплект.** При переносе в существующий проект нужна папка `src/contact` целиком: TSX зависит от соседних компонентов, типов, CSS, изображений и локального шрифта.

## Быстрый запуск

Требуется Node.js **22.13.0 или новее**; сборка проверена с Node.js **24.19.0**. В терминале, открытом в папке комплекта:

```sh
npm ci
npm run dev
```

`npm ci` устанавливает версии из приложенного `package-lock.json`. Откройте адрес, который покажет Vite. Просмотр работает, пока запущен этот процесс. Это обычная локальная веб-страница; встроенный просмотр чата и MCP для её работы не нужны.

Команды проверки и сборки:

```sh
npm run typecheck
npm run build
npm run preview
```

`build` сначала проверяет TypeScript, затем создаёт сайт в `dist`. `preview` запускает локальный просмотр этой сборки. Исходный `index.html` и файлы в `dist` нужно обслуживать веб-сервером, а не открывать двойным щелчком как автономный HTML.

## Подключение в проект

```tsx
import ContactUsPage from './contact';

export default function ContactRoute() {
  return <ContactUsPage />;
}
```

Также доступен именованный импорт `ContactUsPage`. Это компонент Solid.js: состояния созданы через `createSignal`, реактивность и жизненный цикл используют Solid. React и React DOM не требуются. CSS уже подключён в компоненте. Сборщик проекта должен обрабатывать TypeScript, JSX, обычный CSS и локальные изображения/шрифты. Tailwind, внешняя библиотека иконок и загрузка шрифта из Google Fonts не нужны.

Подробный контракт обработчиков, особенности интеграции в существующую оболочку сайта и настройки Solid и SolidStart — в [INTEGRATION.md](./INTEGRATION.md).

## Поведение по умолчанию

API и AI-сервис не подключены. Валидная форма или сообщение помощнику показывают: **“Design reference only. Nothing has been sent.”** Сообщения не отправляются, ответы AI не имитируются. Черновики сохраняются в памяти компонента при переключении и сворачивании; перезагрузка страницы их очищает.

Поля, ошибки и сообщения о результатах остаются обычной HTML-разметкой. На телефоне помощник модальный: фон недоступен, фокус удерживается внутри, Escape закрывает окно. На desktop помощник немодальный. Основная AI-кнопка открывает помощника, кнопка команды — её форму, плавающая Chat продолжает текущий экран.

`showDemoNotice={false}` скрывает служебные полосы. Это настройка отображения, а не включение отправки: без обработчиков останется демонстрационное поведение.
